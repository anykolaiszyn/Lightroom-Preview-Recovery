Lightroom Preview Recovery

Important: this utility recovers cached JPEG previews, not your original RAW, JPEG, TIFF, PSD, or video files. Preview quality and size are limited by what Lightroom saved in its cache.

Before you begin

Keep the original backup unchanged. Work from a copy if you have any doubt, and choose an output location outside the backup.

Select the three inputs

  1. Select the Lightroom catalog file ending in .lrcat.
  2. Select the matching Previews.lrdata folder. It must contain previews.db.
  3. Select an empty or separate output parent folder with sufficient free space. The utility creates its own recovery folder inside it.

Review the preflight summary, then choose Start Recovery.

Where recovered files go

Recovered Lightroom Previews/
  Photos/
    <catalog root>/
      <catalog folder>/
        <image name>.jpg
  Unmapped/
  recovery-report.html
  recovery-report.csv
  recovery-log.txt

All recovered files use the .jpg extension because they are cached JPEG previews.

What the statuses mean

  • Mapped: a preview was matched to catalog filename and folder information.
  • Unmapped: a valid preview was recovered, but no matching catalog record was available; it is stored in Unmapped.
  • Skipped: an equivalent completed output from an earlier run was retained instead of being overwritten.
  • Failed: that record could not be read, decoded, or written. Review the reports and log; other records can still succeed.

Cancel and rerun safely

Choose Cancel to stop after the current safe file operation. A partial report is written. To continue later, select the same inputs and output parent, then start again; already verified completed outputs are skipped and existing files are never overwritten.
