Lightroom Preview Recovery

Recover photos from an old Adobe Lightroom catalog when the original RAW, JPEG, or TIFF files are gone. This free Windows app reads Lightroom's own cached preview JPEGs — stored in the Lightroom Catalog Previews.lrdata folder next to your .lrcat catalog — and saves them as normal image files, with your original folder structure and filenames intact.

Download for Windows

Free. No install, no Python, no Lightroom required. Unzip and run.

How it works

  1. Find your .lrcat catalog file and the matching Lightroom Catalog Previews.lrdata folder sitting next to it on your backup.
  2. Open the app and point it at both — the catalog file and the preview folder.
  3. Choose a new, empty destination folder (not inside the catalog or preview folder).
  4. Click Start recovery. The app finds the best cached copy of each photo and copies it out as a JPEG.
  5. Review the recovered files, plus a full HTML/CSV/log report of what was recovered, skipped, or unreadable.

Frequently asked questions

Can I recover my original RAW files?
No. This tool only recovers the JPEG previews Lightroom already rendered and cached — not your original RAW/JPEG/TIFF/PSD files. Preview quality is whatever Lightroom happened to cache: usually good enough to recognize and use in a pinch, but not a substitute for the original file.
Is it safe to run against my old backup?
Yes. Your catalog and preview cache are opened read-only and are never modified. The app only ever writes to a separate destination folder you choose.
Do I need Lightroom installed?
No. The app reads the catalog and preview files directly; Lightroom does not need to be installed or running.
What if it stops partway through, or I want to add more later?
Just run it again with the same catalog, preview folder, and destination. Already-recovered photos are checked and left alone — only what's missing gets processed. Nothing is overwritten or duplicated.
Why does Windows show a SmartScreen warning?
The app isn't code-signed (that costs money for a solo open-source project). If you downloaded it from the GitHub releases page, click "More info → Run anyway." The source code is public on GitHub.
